# V2A · Video to Audio

macOS 上把视频里的声音取出来的小工具,同时具备下载视频到本地的功能。

macOS 原生风格界面，干净纯粹


## 下载

- 最新版：<https://github.com/Molank/v2a/releases/latest>
- 仓库：<https://github.com/Molank/v2a>

解压后把 `V2A.app` 拖进「应用程序」。首次打开若提示「无法验证开发者」，右键 App → 打开，或执行：

```bash
xattr -dr com.apple.quarantine /Applications/V2A.app
```

需要下载会员内容时，到「偏好设置 → 完全磁盘访问」授权并重启 App。

## 用法一：拖拽 App（推荐）

App 已经装在 `/Applications/V2A.app`，直接打开即可（也可以在启动台 / 聚焦里搜 V2A）。
2. 打开后，把视频文件 —— 或者装着视频的整个文件夹 —— 拖到窗口里。
3. 底栏左侧的胶囊显示当前格式与参数（如「MP3 320 kbps」），点开可以改格式（M4A / MP3 / WAV / FLAC）、码率、采样率、声道、音轨和预设；确认后点「开始提取」。
4. 音频默认生成在**视频同目录**，同名冲突自动变成 `影片 (2).m4a`。

也可以把视频直接拖到 Dock 上的 App 图标，或在 Finder 里用「打开方式」选它。

右上角是三个圆形工具栏按钮：`+` 添加文件、🔗 粘贴视频链接、垃圾桶清空列表（34 pt，与 Finder 工具栏同尺度）。

### 每行的操作

鼠标移上去，行尾会出现「…」菜单；右键也有同样的项：

| 项 | 说明 |
| --- | --- |
| 重命名… | 先给输出起名，或转换完再改（会真的改磁盘上的文件，扩展名自动保留） |
| 裁剪… | 打开波形时间轴，选一段再提取 |
| 在 Finder 中显示 | 转换完成后可用 |
| 移除 | 从列表拿走 |


声道标识会按实际布局显示：单声道、立体声、5.1、7.1，杜比编码（AC-3 / E-AC-3 / TrueHD）显示为「杜比 5.1」，带 Atmos 的显示「杜比全景声」。

### 裁剪

点「裁剪…」打开的是一条**波形时间轴**，跟剪辑软件一样：

- 波形由自带 ffmpeg 解码 8 kHz 单声道 PCM 后取峰值绘制；偏安静的素材会适度归一化显示。
- 左右两个白色拉手拖动选择范围，选区内明亮、选区外压暗。
- 拖动播放头定位，空格键播放/暂停（打开面板时不会自动聚焦输入框），播到结束点自动停。
- 下方的「开始 / 结束」仍可直接输入时间码（`0:08` 或 `8`）；输入中按 Esc 退出输入态，再按 Esc 关闭面板。
- 应用后，行里会显示 `裁剪 0:02–0:06`，体积预估也按裁剪后的长度重算。

### 文件大小

每行右侧两行数字：

- 上：源文件大小
- 下：`≈` 转换后预估大小；转换完成变成 `→` 实际大小


### 音频设置（齿轮按钮）

| 项目 | 说明 |
| --- | --- |
| 比特率 | 64 / 96 / 128 / 160 / 192 / 256 / 320 kbps，只对 M4A、MP3 生效 |
| 采样率 | 跟随源 / 22.05 / 44.1 / 48 / 96 kHz |
| 输出声道 | 跟随源 / 单声道 / 立体声 |
| 音轨 | 自动列出视频里的每条音轨（带语言和声道信息），默认第 1 条 |

「跟随源」且源音轨已是目标编码时会**直接抽流**，不重新编码；一旦指定采样率或声道，就会强制重编码。

### 预设

- 设置好之后点「存为预设…」，起个名字（比如「播客 320k」），写进偏好设置。
- 之后在底部的预设菜单里随时切换，选中时菜单里打勾、左侧书签图标变为实心，标题下方也会显示预设名。
- 预设菜单里可以删除；设置一旦偏离某个预设，菜单就显示「自定义设置」。

## 用法三：粘贴链接直接下载

点右上角的 🔗 会打开独立的「下载链接」窗口；在主窗口里按 ⌘V 粘贴链接，也会打开同一个窗口并预填地址，两处共用一套选项（主窗口没有输入框，⌘V 由 AppKit 事件监听接管，只在主窗口且不在编辑文本时生效）。

- 后端是 **yt-dlp**，支持 **1700+ 站点**：YouTube、Bilibili、Vimeo、抖音、优酷、X/Twitter、Twitch、Instagram…，以及任意直链（`.mp4` 之类）
- 下载 **≤1080p** 的最佳画质，音视频分离时用自带 ffmpeg 自动合并成 mp4（音频是 FLAC 时自动改用 mkv）
- 行内的音频码率来自流信息；mkv 这类不写 per-stream 码率的容器会退化为容器均值或前 400 个包的估算
- 默认保存到「下载」文件夹（可在「设置 → 下载」里改，链接窗口的说明文字会跟着变），完成后**直接变成列表里的普通一行**，后面的裁剪/预设/提取流程完全一样；也可以勾选「下载完成后在 Finder 中显示」
- 分享文案里夹着的链接也能识别（会自动抠出第一个 http 链接，比如 B 站 App 的「复制链接」）
- 粘贴链接后会先**预览**：封面、标题、时长、UP 主，确认无误再点下载。
- **仅下载音频**：只取音轨，不下载视频（配合最高品质可拿 FLAC）。
- **下载最高品质（音质 / 画质）** 是一个可选开关：不开时按 ≤1080p 下载、不读 Cookie、不需要任何授权；勾选后不再限制分辨率（有 4K / 8K 取最高），音频取最佳（B 站会员内容可到 FLAC），同时启用浏览器 Cookie。勾选时若还没选浏览器或没给「完全磁盘访问」，弹窗里会直接出现橙色提示和「去授权」按钮。
- **登录站点**：弹窗里可选「从浏览器读取 Cookie」（Safari / Chrome / Edge / Firefox），只在勾选「最高音质」时使用
- **底栏右侧的齿轮 = 偏好设置**（菜单栏「V2A → 偏好设置…」也能打开）：里面是权限状态（完全磁盘访问未授权时右侧直接给「去授权」，点它会打开系统设置并浮出拖拽条；浏览器 Cookie 会实际去钥匙串读一次密钥——已授权就静默显示「已授权」，没授权才弹窗）、「下载」（默认保存目录 + 下载后自动在 Finder 显示）和「关于」（版本 1.0.0、作者 @Bowie）。
- **首次启动会弹一个「下载授权」提示**，只讲完全磁盘访问这一项（浏览器 Cookie 的解释放在设置和下载窗口里，避免第一次打开就被两个权限吓到）：从 Safari 读 Cookie 需要「完全磁盘访问」，从 Chrome/Edge 读 Cookie 首次会弹钥匙串授权。点「打开系统设置」后还会浮出一条**无边框的拖拽条**：拖动中间的白色内板 = 把 App 拖进「完全磁盘访问」列表；拖动外圈留白 = 移动这个悬浮条本身。不用再去 Finder 里找 App。
- **B 站 Hi-Res**：普通音轨最高 192k AAC；`dash.flac`（Hi-Res，格式 30251）和杜比（30250）只在**视频本身带 Hi-Res + 登录大会员**时才会返回，未登录时接口里是 `null`。勾选「仅下载音频」并在「登录站点」里选浏览器读 Cookie，就会直接拿到 FLAC；完整视频模式也会用 `mp4/mkv` 兜底，避免 FLAC 塞不进 mp4。
- YouTube 需要能访问的网络；另外新版 yt-dlp 处理 YouTube 的部分签名需要 JS 运行时，机器上有 node 时会自动用

## 用法二：命令行 `v2a`

App 之外还有一个命令行版本，适合脚本和批量：

```bash
./v2a 影片.mp4                    # 同目录生成 影片.m4a
./v2a -f mp3 -b 320k 影片.mkv     # 指定格式和码率
./v2a -f wav -a 1 演唱会.ts       # 取第 2 条音轨，转 wav
./v2a -o ~/Music 某个文件夹        # 批量输出到指定目录
```

参数：`-f m4a|mp3|wav|flac|aac`、`-b 码率`、`-a 音轨号`、`-o 输出目录`、`-h`。

想在任何目录直接敲 `v2a`，把这个目录加进 PATH 即可（例如在 `~/.zshrc` 里）：

```bash
export PATH="/Users/bowie/Documents/deepseek-harness/default-workspace/video-to-audio:$PATH"
```

## 其他细节

- 一次可拖多个文件/文件夹，逐个处理，行内显示进度。
- 转码中可以点「取消」中断。
- 支持 mp4 / mov / m4v / mkv / avi / flv / webm / ts / m2ts / wmv / mpg / 3gp / rmvb / vob / ogv / mxf / asf。
- 网络受限时（例如没有代理的 YouTube），下载行会直接显示失败原因，不影响本地文件处理。


## 内置了什么

`V2A.app` 自带 ffmpeg / ffprobe（arm64 静态版 6.0，约 88 MB），**不依赖本机安装的 ffmpeg**。

## 卸载

把 `/Applications/V2A.app` 拖到废纸篓即可，没有后台进程或开机项。若想连偏好一起清掉（预设、上次的音频设置、窗口位置）：

```bash
defaults delete com.bowie.v2a
```

## 已知取舍

- 多音轨视频默认第 1 条，可在设置里切换；命令行用 `v2a -a N`。
- 裁剪对「直接抽流」同样生效（在输入侧 `-ss` / `-t` 定位），因此切点可能落在最近的音频帧边界，误差通常 < 50 ms。
- WAV 输出为 16-bit PCM；FLAC 体积预估按原始 PCM 的 55% 估算（经验值，实际 40–70%）。
- 音频不写入封面图；元数据（标题/艺术家等）会保留。
- 调试用的隐藏参数：`--snapshot <png>`、`--files`、`--set 格式/码率/采样率/音轨/声道`、`--trim 开始/结束`、`--name 名字`、`--convert`、`--popover`、`--show-trim`、`--show-rename`、`--save-preset`。
